# minimical.finance

Internal finance and invoicing OS for Minimical.

## First build
- Dashboard KPIs
- Search and invoice filters
- Invoice records seeded from the current Elle tracker
- Payment status
- Invoice detail drawer
- Structured invoice Contents
- Priced, unpriced/TBD, adjustment and note content types
- Automatic totals and integrity warnings
- New invoice composer

Supabase/Postgres persistence is the next integration layer.
